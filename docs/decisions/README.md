# Decisions

One file per decision that would otherwise be re-argued every few weeks. Each
records what the situation was, what was decided, and what it costs — because a
decision without a price recorded is usually a decision that was never really made.

Dates are the day the decision was taken, where it is known. A decision that later
turned out to be wrong is not edited away; it is superseded by a new one that says
so.
